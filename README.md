# Student Marks Prediction using Linear Regression

Predicts a student's marks from the number of study hours using Linear Regression.

## Workflow
Define Problem → Collect Data → Understand/Clean Data → Choose X and y → Split into Train and Test → Create Linear Regression Model → Train Model → Model learns m and c → Make Predictions → Compare Actual vs Predicted → Evaluate Model

## Evaluation Metrics
MAE, MSE, RMSE and R² Score

## Tools Used
Python, Pandas, NumPy, Matplotlib, Scikit-learn

## How to Run
1. Install the libraries: `pip install numpy pandas matplotlib scikit-learn`
2. Open `Student_Marks_Prediction.ipynb` in Jupyter Notebook, VS Code or Google Colab
3. Run all cells
